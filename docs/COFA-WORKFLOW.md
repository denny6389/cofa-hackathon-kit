# 참가자 진행 체크리스트

최신 운영 공지와 실제 과제 README·제공 환경의 지침이 이 일반 안내보다 우선한다. 아래는 제공된 Cofa 가이드의 Codex·Browser·MCP·저장·제출·서술형·FAQ 절과 이후 공지를 정리한 참고다. kit 제작자가 실제 Cofa 연동이나 시험 동작을 독립 검증한 결과는 아니다. 비공개 가이드 PDF·메일·체험 과제·스크린샷은 공개하지 않는다.

## 시작과 질문

- [ ] 실제 과제 README와 기존 규칙, 작업·제출 경로, 필수 문서의 이름·경로·완료 조건을 확인한다. `uploads`의 역할이나 제출 범위를 추측하지 않는다.
- [ ] 제공 터미널에서 `codex`를 실행하고 `/status`, `/model`로 상태·허용 모델을 확인한다. Codex를 업그레이드하거나 개인 AI 키·구독·외부 AI를 연결하지 않는다.
- [ ] Codex의 **승인 대기 / 실행 중 / 완료**를 구분한다. 승인 대기를 오류나 완료로 오해하지 않는다.
- 업무 맥락은 제공 시나리오 실무자에게, 화면·제출 방법은 Cofa Helper에게 묻는다. 반복 오류·감독 연결 문제는 운영 측에 알린다.

10월 29일 후속 공지는 Chrome 사용, Codex 업그레이드 금지, 추가 안내 메일 **09:40**을 안내했다. 이전의 09:50 안내 대신 후속 공지를 참고하되 당일 최신 공지를 다시 확인한다. 참가자가 Chrome에서 플랫폼을 이용하는 것과 AI가 외부 브라우저·Computer Use를 조작하는 것은 구분한다.

## 구현·저장·화면 확인

- [ ] 기능 하나의 계획을 승인하고, 그 범위에서 구현·검증·수정을 진행한다. diff와 결과를 승인한 뒤 다음 기능으로 넘어간다.
- [ ] 필수 요구사항을 출처·구현 위치·검증 입력·독립 기대 결과·실제 근거와 연결한다. 필수 계획·협업·제출 문서에 요구사항·구현 이유·구현 내용·검증 근거·한계를 갱신한다. 공식 파일명이나 양식을 새로 만들어 주장하지 않는다.
- [ ] 서버는 `0.0.0.0`에 바인딩하고 실제 포트·경로를 확인한다. `3000`은 예시다. 서버 터미널을 유지하고 플랫폼 Browser에서 참가자가 입력·버튼·화면 이동을 확인한다. 별도 터널은 필요 없다.
- [ ] AI 검사와 참가자의 Browser 관찰을 구분한다. 사람 확인 전에는 `HUMAN_CHECK`(확인 대기)이며 `PASS`가 아니다. 실제 확인 뒤에만 관찰 결과를 기록한다.
- [ ] 저장 충돌이 나면 편집기 버전과 AI·터미널 버전을 비교한 뒤 보존할 내용을 선택한다. 선택 후 실제 저장 상태를 확인한다.

## MCP가 꼭 필요할 때만

1. 과제에 필요한 기능이 기존 도구로 해결되는지 먼저 비교한다. 외부 예제나 MCP를 기본 설치하지 않는다.
2. 대회 규정과 과제 안내에서 허용 범위를 확인하고, 설정은 제공 MCP 탭에서 진행한다. 코드·접근 권한·데이터 흐름·외부 전송을 확인하고 기존 서버와 JSON 설정을 보존한다. 새로운 JSON 스키마를 추측하지 않는다.
3. 가이드는 MCP 탭의 저장이 준비된 Codex 설정에 반영된다고 안내한다. 저장 후 실제 도구 호출을 시험해 동작을 확인한다. 지원 안내만으로 연결 성공을 기록하지 않는다.
4. 동작하지 않으면 허용된 기존 도구로 진행한다. 시험 자료의 외부 전송, 새 개인 AI 연결, 제한 우회는 허용되지 않는다.

## 제출 확정 전

- [ ] 작업 타이머 종료 **약 10분 전 제출 준비를 권장**한다. 실제 시각·타이머를 보고 판단하며 보고·재접속으로 시간이 멈춘다고 생각하지 않는다.
- [ ] 필수 기능·문서·파일명·경로와 저장 상태, 실제 제출 범위를 README·Helper로 확인한다. 별도 kit 폴더도 자동 제외된다고 가정하지 않는다.
- [ ] 미리보기는 제출 파일의 일부만 보여줄 수 있다. 미리보기를 전체 제출 목록으로 취급하지 않는다.
- [ ] 확정 전에 입력→처리→출력, 구현 선택 이유, 검증·한계를 스스로 설명할 수 있게 정리한다.
- [ ] 제출 확정은 파일을 잠근다. 확정 뒤에는 수정할 수 없으므로 확인 후 확정한다.

## 서술형과 종료

- 제출 확정 후 서술형 답변은 **AI·붙여넣기 없이 직접 작성**한다. 실제 문항 수와 제한 시간은 화면을 확인한다. FAQ의 안내는 6문항×각 5분이지만 실제 문항 수를 고정해서 가정하지 않는다. 이전 문항으로 돌아갈 수 없다.
- 질문 생성 대기를 고정 5분으로 가정하지 않는다. 가이드는 최대 10분과 재시도를 안내한다. 전체 종료 시각 **14:00**과 최신 운영 안내를 함께 확인한다.
- [ ] 답변·업로드 처리가 끝났는지 확인하고 완료 접수증의 ID·시각·파일 수·용량을 확인한 뒤 종료한다. kit에는 접수증이나 시험 자료를 올리지 않는다.
- 오류는 발생 시각·단계·실행 행동·오류 내용을 비밀정보 없이 운영 측에 보고한다. 보고나 재접속 중에도 타이머는 멈추지 않는다.

사전 체험은 1회 15분이며 이 kit의 참가자는 이미 완료했다. 아래는 일반 참고용으로, 재체험 지시가 아니다.

- [ ] 감독 연결·제공 환경, Codex 상태·모델을 확인한다. 업데이트하지 않는다.
- [ ] 기존 지침과 필요한 Skill 파일을 읽을 수 있는지 확인한다.
